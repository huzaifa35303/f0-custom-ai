# f0undr Ai

A chat assistant that answers from live web search and from what you teach it.
No model, no API key, no dependencies.

The app lives in [`web-chat/`](web-chat) — see its
[README](web-chat/README.md) for how it works.

```bash
cd web-chat
npm start          # http://localhost:3000
```

Node 20 or newer. There is nothing to install.
